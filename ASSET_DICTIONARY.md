# F1 Owner — Asset Dictionary

Every image is served from `public/assets/images/<category>/<file>` and
declared in `src/data/assets.ts` (`assetManifest` + `assetPaths`).

## How to replace placeholder art

1. Find the file in the table below (or the folder `public/assets/images/<category>/`).
2. Overwrite that file with your real image — **keep the same filename**.
3. Refresh. No code changes, no rebuild needed.

Real art already dropped in for: `dummy021.png`, `dummy022.png`, `dummy023.png`, `dummy024.png`, `dummy029.png`.
